# Portafolio de Carolina Pantoja

Sitio estático de diseño gráfico: HTML, CSS y JavaScript, sin dependencias
ni paso de compilación. Se publica con GitHub Pages.

- Inicio: `index.html`
- Páginas de proyecto: `proyectos/*.html`
- Contenido de los proyectos (textos, imágenes, orden): `src/data/proyectos.js`
- Estilos base: `styles.css` · Estilos de proyecto: `proyectos/proyecto.css`

## Cómo actualizar

1. Edita el archivo correspondiente.
2. Si cambias un CSS o un JS, sube el número de versión en el HTML
   (`styles.css?v=39`), para que los navegadores no muestren la versión vieja.
3. Sube los archivos al repositorio; GitHub Pages publica solo en 1–2 minutos.
